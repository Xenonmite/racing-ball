# How to play
This is a relatively simple game where you play as a white ball and have to defeat as many waves of enemies as you can. Killing enemies gives some fuel which is used for healing and attacking, as well as passively. If you run out of either fuel or HP you die. Your highscore is saved on death.

If you have Python installed you can execute **run.bat** to install the dependencies and launch the game (afterwards running **main.py** will also work).

Join my server at https://discord.gg/RxvvGhBWUq to share your highscore, if you have questions, or for no reason.

# Controls
* WASD to move
* Left click to fire
* 1/2/3/4 to switch weapons (weapon 4 does not drop fuel or score when ***killing***)
* Spacebar to quickly stop moving (good for some weapons\' recoil)
* Hold C to heal (uses fuel)
* Period/comma to make music louder/quieter
* M to stop music
* K to randomize current song
* ESC to pause
* T to switch background

## Extras
* You can freely resize the window
* You can add any .mp3, .ogg, or .wav file to the music folder and the game should play it
